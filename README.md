# Pharo Arrow

## Installation

### Pharo

```sh
Metacello new
	baseline: 'PharoArrow';
	repository: 'github://badetitou/PharoArrow:main/src';
	load.
```

### Mac

```sh
brew install apache-arrow apache-arrow-glib
```

### Linux

You should install

- `libarrow-dev`
- `libarrow-glib-dev`
- `libparquet-dev`
- `libparquet-glib-dev`
